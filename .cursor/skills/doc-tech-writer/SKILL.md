# Doc Tech Writer

Используй этот skill, когда пользователь просит `/doc`, `/tech-writer`, документацию по задаче, обновление `CHANGES.LOG` или актуализацию существующих документов в `docs/`.

Запусти ровно один субагент `tech-writer` с:

- `readonly: false` — субагент создаёт и правит файлы документации
- `run_in_background: false`, если пользователь явно не просит фоновый запуск
- `description: "Tech Writer"`
- `subagent_type: "tech-writer"`

Используй корень активного workspace как `Full Repository Path`.

Форма промпта:

```text
Full Repository Path: <абсолютный путь к репозиторию>
Task: <что задокументировать: задача, фича, модуль, приложение>
Scope: <одно из: "new docs", "update existing", "changelog only", "full sync docs+changelog">
Context: <контекст из чата: что сделано, ссылки на PR/коммиты, затронутые файлы кода>
Target Docs: <пути docs/... или приложение: API, Manager, Server и т.д. — если известно>
Source Changes: <одно из: "git diff", "git log", "described in chat", "specific commits">
Custom Instructions: <только если пользователь дал особые требования к формату или языку>
```

- По умолчанию `Scope`: `update existing` или `new docs` — по смыслу запроса.
- Если пользователь просит только журнал изменений — `Scope: changelog only`.
- Для описания недавней разработки укажи `Source Changes: git diff` или `uncommitted changes`, если релевантно.

Субагент сам исследует код и существующую документацию. Не пиши документацию вместо субагента, если пользователь явно не попросил сделать это в основной сессии.

Если субагент завершился с ошибкой:

- Исправь некорректный вызов (путь, форма промпта) и повтори один раз.
- При других сбоях — один повтор с тем же промптом.
- Если снова неудача — кратко сообщи о блокере.

После завершения субагента:

- Верни список изменённых файлов `docs/...` и краткое резюме.
- Укажи, добавлены ли записи в `CHANGES.LOG`.
- Если остались пробелы в документации — перечисли их кратко.

Не вноси правки в прикладной код, если пользователь явно не попросил и документацию, и код в одной сессии.
