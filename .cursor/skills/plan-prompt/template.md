# Prompt file template

Polished task thesis for manual handoff to the orchestrator. Prose in Russian.

```markdown
# `agent_work/inbox/<task-name>_prompt.md`
**Created**: `YYYY-MM-DD HH:MM`

> <Тезис в 1–2 предложения: что сделать и зачем>

## Суть задачи

<Один абзац: контекст, проблема, желаемый результат — связный текст, не список заголовков>

## Проблема

<Что не устраивает сейчас, почему это важно>

## Желаемый результат

<Как должно выглядеть / работать после выполнения>

## Цели

1. …
2. …

## Вне scope

- …

## Затрагиваемая область

<Модули, экраны, файлы — насколько известно; «уточнит Architect» если неясно>

## Ограничения

- **Нельзя ломать:** …
- **Обязательно сохранить:** …

## Критерии готовности

- [ ] …
- [ ] …

## Риски и неясности

<Только если обсуждались; иначе «—»>

## Исходные формулировки заказчика

> <цитаты из интервью — якорь намерения>

---

**Task slug:** `<task-name>`  
**Handoff:** `/orchestrator <task-name>`
```
