# Как открыть дополнительные настройки виджета

На каждом виджете (принтер, камера, сканер, перевозчик, генератор) редко используемые параметры спрятаны в блок **«Дополнительно»**. Основные элементы — название, кнопки «R» / «S», статус и очередь кодов — всегда видны на карточке.

**Где найти:** кнопка «Дополнительно» под шапкой виджета на боковой панели или в основной области.

## Что всегда видно на карточке

- поле названия виджета;
- кнопки «R» (запуск) и «S» (остановка), кнопка «X» (удаление);
- ключевой статус работы;
- список очереди кодов (перетаскивание кодов в список по-прежнему работает).

Эти элементы **не** скрываются при свёрнутом «Дополнительно».

## Раскрытие дополнительных настроек

1. Найдите кнопку «Дополнительно» на нужном виджете (по умолчанию блок свёрнут).
   **Результат:** рядом с надписью видна стрелка, указывающая, что блок можно раскрыть.
2. Нажмите «Дополнительно» один раз.
   **Результат:** под кнопкой появляются дополнительные поля — порты, интервалы, связи «ИЗ:» / «В:», параметры COM и другие настройки типа виджета.
3. Чтобы снова спрятать поля, нажмите «Дополнительно» ещё раз.
   **Результат:** дополнительные поля скрыты; название, «R» / «S» и очередь кодов остаются на месте.

## Что находится в «Дополнительно» (по типам)

| Тип виджета | Примеры настроек в блоке |
|-------------|--------------------------|
| Принтер | сетевой порт, буфер |
| Камера | интервал, пакетная отправка, обработка no-read и дубликатов |
| Сканер | параметры COM-порта, суффикс, связанные опции |
| Перевозчик | интервал передачи, списки «ИЗ:» и «В:» |
| Генератор | тип кода, GTIN, интервал, список «В:» |

Точный набор полей зависит от типа устройства; подписи на форме совпадают с прежними версиями эмулятора.

## Сохранение состояния «Дополнительно»

- Новый виджет добавляется со **свёрнутым** «Дополнительно».
- Если блок был раскрыт или свёрнут, это запоминается в файле конфигурации линии **после** «Файл» → «Сохранить».
- При открытии сохранённого файла каждый виджет восстанавливает своё состояние «Дополнительно».

Тема оформления (светлая / тёмная) на состояние «Дополнительно» не влияет.

## Если что-то пошло не так

| Ситуация | Что делать |
|----------|------------|
| Не вижу «ИЗ:» / «В:» у перевозчика | Нажмите «Дополнительно» на карточке перевозчика — списки связей в этом блоке. |
| Не вижу интервал камеры | Раскройте «Дополнительно» на виджете камеры. |
| После открытия файла все блоки свёрнуты | Так бывает для старых файлов, сохранённых до этой версии; раскройте нужные вручную и сохраните файл снова. |
| Нужно изменить порядок виджетов | Используйте «≡» в шапке — см. [Расположение и порядок виджетов](layout-and-docking.md). |
