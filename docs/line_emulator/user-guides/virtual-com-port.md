# Как настроить виртуальный COM-порт для сканера

Программа не создаёт COM-порты сама — она только показывает порты, которые уже есть в Windows, и пишет в выбранный. Для проверки сканера без физического оборудования удобно связать два виртуальных порта: в один пишет эмулятор, из второго читает ваша тестовая программа.

**Где найти:** настройка выполняется в Windows до запуска эмулятора; в программе порт выбирается в виджете «Сканер».

## Перед началом

- Компьютер с Windows и правами администратора для установки драйвера.
- Установленный драйвер виртуальных портов (ниже — пример с **com0com**).

## Установка com0com

1. Скачайте установщик com0com с [страницы проекта на SourceForge](https://sourceforge.net/projects/com0com/).
2. Запустите установку **от имени администратора**.
   **Результат:** в системе появляется утилита **Setup** для управления парами портов.
3. Если Windows блокирует драйвер, следуйте инструкции к вашей версии установщика (подпись драйвера, режим тестирования и т.п.).

## Создание пары портов

1. Откройте утилиту Setup com0com.
2. Добавьте новую пару портов (кнопка **Add pair** или аналог).
   **Результат:** в списке появляются два связанных имени, например `COM5` и `COM6` (номера зависят от компьютера).
3. Убедитесь, что оба порта **включены**.
   **Результат:** порты видны в диспетчере устройств и в списке «COM-порт» в эмуляторе.

Схема работы:

```text
Эмулятор (сканер)  →  COM5  ↔  COM6  →  Ваша программа-приёмник
```

Данные, записанные в один порт пары, появляются при чтении из второго.

## Подключение в эмуляторе

1. Запустите «Эмулятор производственной линии».
2. Добавьте сканер: «Добавить» → «Сканер».
3. В «COM-порт» выберите **один** порт из пары (например, `COM5`).
4. Запустите сканер кнопкой «R» и отправьте тестовый код.
   **Результат:** на втором порте пары (например, `COM6`) приёмник видит строку с кодом.

Подробнее о работе сканера — в [инструкции по виджету сканера](scanner-widget.md).

## Проверка приёма

Откройте любую программу для работы с COM-портом (терминал PuTTY, Tera Term и т.п.):

1. Выберите **второй** порт пары (не тот, что в сканере).
2. Установите скорость **9600**, 8 бит, без чётности, 1 стоп-бит.
3. Отправьте код из эмулятора вручную или из очереди.
   **Результат:** в терминале появляется строка с кодом.

## Если что-то пошло не так

| Ситуация | Что делать |
|----------|------------|
| Порт не появляется в списке «COM-порт» | Переустановите или включите пару в Setup com0com; в виджете сканера нажмите кнопку обновления списка портов (между «COM-порт» и «R»). |
| «Порт занят» при запуске сканера | Закройте терминал или другую программу, которая уже открыла этот COM. |
| Данные не видны на втором порте | Убедитесь, что читаете **другой** порт той же пары и скорость 9600. |
| После перезагрузки порты пропали | Снова создайте или включите пару в Setup com0com. |
