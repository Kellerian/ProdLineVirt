# Как настроить задержку передачи кодов

Интервал задаёт паузу для **каждого кода отдельно**: отсчёт начинается в момент, когда код попадает в очередь узла. Коды обрабатываются **по порядку** — следующий не уйдёт раньше предыдущего. При переходе на следующий узел линии для кода начинается новый отсчёт.

У **перевозчика** интервал действует дважды: код должен «созреть» в очереди источника, и между **соседними передачами** перевозчика должна пройти та же пауза. Это важно, когда источник (например, принтер) отдаёт сразу много кодов — перевозчик не выгружает их пачкой, а передаёт по одному с заданным интервалом.

**Где найти:** виджеты «Камера», «Перевозчик» и «Генератор» на рабочем поле главного окна «Эмулятор производственной линии».

## Перед началом

- Устройства добавлены через меню «Добавить».
- Для перевозчика и генератора выбран приёмник в списке «В:».
- Для отправки кодов с камеры нажата кнопка «R» на виджете (она станет красной «S» — режим работы).

## Камера

1. Откройте вкладку «Обмен» на виджете камеры.
   **Результат:** видны поля «ПАКЕТ» и «ИНТЕРВАЛ».
2. В поле «ИНТЕРВАЛ» укажите паузу в миллисекундах (например, `1000` — одна секунда на код).
   **Результат:** каждый код во вкладке «IN» будет отправляться только после истечения этого времени с момента попадания в список.
3. В поле «ПАКЕТ» укажите, сколько кодов отправлять за один раз (например, `1` — по одному, `3` — пачкой из трёх).
   **Результат:** пачка уйдёт только когда **все** коды пачки с начала очереди «созрели» — для каждого прошло указанное в «ИНТЕРВАЛ» время.
4. Добавьте коды во вкладку «IN» (перетаскиванием или из генератора) и включите камеру кнопкой «R».
   **Результат:** коды появляются во вкладке «OUT» с заданной паузой; порядок в списке «IN» сохраняется.

Интервал можно менять во время работы — для кодов, уже стоящих в очереди, время пересчитывается по новому значению.

## Перевозчик

1. На виджете перевозчика в поле «ПЕРЕДАВАТЬ КАЖДЫЕ:» укажите паузу в миллисекундах.
   **Результат:** код из очереди источника («ИЗ:») перейдёт в приёмник («В:») только после истечения этого времени с момента попадания в исходящую очередь источника; следующий код уйдёт не раньше, чем пройдёт такая же пауза после предыдущей передачи.
2. В списке «ИЗ:» выберите устройство-источник, в «В:» — приёмник (обычно камеру).
   **Результат:** связь маршрута задана.
3. Нажмите «R» для запуска перевозчика.
   **Результат:** коды по одному передаются дальше по линии с указанной паузой; в приёмнике для каждого кода отсчёт начинается заново.

Интервал можно менять во время работы — для уже стоящих в очереди кодов время до передачи пересчитывается; пауза между соседними передачами перевозчика подстраивается под новое значение.

## Принтер → перевозчик → камера

Типичная цепочка: клиент отправляет на принтер сразу несколько кодов, перевозчик забирает их из буфера принтера и передаёт в камеру.

1. Добавьте принтер через меню «Добавить» → «Принтер», настройте порт и запустите принтер кнопкой «R».
   **Результат:** принтер принимает коды от клиента; они появляются в списке «Буфер:».
2. Добавьте перевозчик и камеру, в «ИЗ:» выберите принтер, в «В:» — камеру.
3. В поле «ПЕРЕДАВАТЬ КАЖДЫЕ:» укажите нужную паузу (например, `500` — полсекунды между кодами).
4. Запустите перевозчик и камеру кнопками «R».
   **Результат:** даже если в буфере принтера сразу появилось много кодов, в камеру они приходят **по одному** с паузой «ПЕРЕДАВАТЬ КАЖДЫЕ:» — не пачкой за доли секунды.
5. На камере задайте свой «ИНТЕРВАЛ» и «ПАКЕТ» — для каждого пришедшего кода отсчёт на камере начинается заново.
   **Результат:** задержки принтера, перевозчика и камеры складываются по порядку прохождения кода по линии.

## Генератор

1. На виджете генератора в поле «НОВЫЙ КОД КАЖДЫЕ:» укажите паузу между появлением кодов в миллисекундах.
   **Результат:** новые коды будут добавляться в очередь выбранной камеры (вкладка «IN») с этим интервалом.
2. В списке «В:» выберите камеру-приёмник.
3. При необходимости укажите тип кода и GTIN, затем нажмите «R».
   **Результат:** генератор создаёт коды с заданной паузой; камера обрабатывает их по своим настройкам «ИНТЕРВАЛ» и «ПАКЕТ».

## Сохранение настроек

1. Выберите «Файл» → «Сохранить» или «Сохранить как...».
   **Результат:** значения интервала для камер, перевозчиков и генератора записываются в файл конфигурации.
2. Откройте сохранённый файл через «Файл» → «Открыть...».
   **Результат:** интервалы подставляются в соответствующие поля виджетов.

## Если что-то пошло не так

| Ситуация | Что делать |
|----------|------------|
| Код долго стоит в очереди «IN» камеры | Подождите — возможно, ещё не истёк «ИНТЕРВАЛ» для этого кода или для кода перед ним в очереди. |
| Пачка из нескольких кодов не уходит | Убедитесь, что в начале очереди достаточно кодов и для **каждого** из них прошло время «ИНТЕРВАЛ»; пачка не отправляется, пока не «созрели» все коды пачки с начала списка. |
| Перевозчик не передаёт коды | Проверьте, что перевозчик запущен («S»), выбраны «ИЗ:» и «В:», в исходящей очереди источника есть коды. |
| Из принтера в камеру уходит сразу много кодов без паузы | Убедитесь, что перевозчик запущен и в «ПЕРЕДАВАТЬ КАЖДЫЕ:» задан нужный интервал; коды должны уходить по одному с этой паузой. Если пауза слишком мала, увеличьте значение. |
| Камера отправляет пачку из нескольких кодов | Проверьте «ПАКЕТ» на камере — значение больше 1 означает штатную пакетную отправку, это не ошибка перевозчика. |
| Генератор не выдаёт коды | Проверьте запуск («S»), выбран ли приёмник «В:», заполнен ли GTIN (если требуется для типа кода). |
| После смены интервала поведение кажется другим | Это нормально: для кодов уже в очереди время до отправки пересчитывается по новому значению. |
