# Как установить эмулятор на Debian или Ubuntu

На компьютере с **Debian 12** или **Ubuntu 22.04** (и новее) эмулятор можно поставить из готового установочного файла `.deb`. После установки программа появляется в меню приложений и запускается как обычное графическое приложение.

**Где найти:** установочный файл `.deb` выдаёт тот, кто собирает пакет (имя вида `dmclineemulator_…_amd64.deb`). После сборки с Windows-хоста через WSL тот же файл может лежать рядом с `dmcLineEmulator.exe` в папке `build/install/dmcLineEmulator/`.

## Перед началом

- Компьютер с **Debian** или **Ubuntu**, архитектура **64-bit (amd64)**.
- Права администратора (`sudo`) для установки и удаления пакета.
- Готовый файл `.deb` той же «ветки» системы, на которой его собирали (пакет с более новой Ubuntu может не запуститься на более старом Debian).
- Графический рабочий стол (нужен экран для окна эмулятора).

## Установка

1. Скопируйте файл `.deb` на компьютер (например, в папку «Загрузки»).
2. Откройте терминал и перейдите в папку с файлом.
3. Установите пакет (подставьте точное имя файла, которое вам передали):

   ```bash
   sudo dpkg -i dmclineemulator_*_amd64.deb
   ```

   **Результат:** пакет установлен; в меню приложений появляется пункт **dmcLineEmulator**.

4. Если установка сообщила о недостающих зависимостях, выполните:

   ```bash
   sudo apt-get install -f
   ```

   **Результат:** система доустанавливает нужные библиотеки и завершает установку.

## Запуск

1. Откройте меню приложений рабочего стола.
2. Найдите и запустите **dmcLineEmulator**.
   **Результат:** открывается окно эмулятора производственной линии.

Альтернатива из терминала:

```bash
/opt/dmclineemulator/dmcLineEmulator
```

## Удаление

В терминале:

```bash
sudo apt remove dmclineemulator
```

или:

```bash
sudo dpkg -r dmclineemulator
```

**Результат:** программа исчезает из меню; файлы приложения удаляются с компьютера.

## Если что-то пошло не так

| Ситуация | Что делать |
|----------|------------|
| `dpkg` пишет о незакрытых зависимостях | Выполните `sudo apt-get install -f`, затем снова откройте программу из меню. |
| Пункт меню не появляется | Выйдите из сеанса и войдите снова или перезагрузите компьютер; убедитесь, что установка прошла без ошибок. |
| Программа не запускается после установки с другой версии Ubuntu/Debian | Установите пакет, собранный на той же или совместимой системе (той же «ветки»). |
| Нужен доступ к COM/USB-порту для сканера | Пользователь должен иметь право работать с устройством порта (часто группа `dialout`); после добавления в группу — перелогин. |
