# Как перетаскивать коды между виджетами

Коды можно переносить мышью из одного списка в другой — удобно для быстрой проверки цепочки линии без генератора и перевозчика.

**Где найти:** главное окно «Эмулятор производственной линии» — списки кодов на виджетах «Принтер», «Камера» и «Сканер».

## Перед началом

- На поле есть хотя бы два виджета с подходящими списками (см. таблицу ниже).
- В списке-источнике есть одна или несколько строк с кодами.

## Откуда и куда можно перетащить

| Откуда | Куда | Что происходит |
|--------|------|----------------|
| Список кодов на **принтере** | Очередь на **сканере** (подсказка «Список очереди (перетащите коды сюда)») | Коды попадают в очередь сканера |
| Список кодов на **принтере** | Вкладка **«IN»** на **камере** | Коды попадают во входную очередь камеры |
| Вкладка **«OUT»** на **камере** | Вкладка **«IN»** на той же **камере** | Обработанные коды возвращаются во входную очередь |

При переносе код **исчезает из источника** и появляется в приёмнике (перемещение, а не копирование). Можно выделить несколько строк и перетащить их вместе.

## Пошаговая инструкция

1. Выделите одну или несколько строк в списке-источнике (принтер, «OUT» камеры).
   **Результат:** строки подсвечены.
2. Зажмите левую кнопку мыши и перетащите коды на целевой список (очередь сканера или «IN» камеры).
   **Результат:** при наведении на приёмник курсор показывает, что сброс возможен.
3. Отпустите кнопку мыши.
   **Результат:** коды появляются в целевом списке и исчезают из источника.

Для камеры и сканера после попадания в очередь начинается отсчёт интервала с момента вставки (см. [Задержка передачи кодов](code-interval.md)).

## Текст извне (блокнот, буфер обмена)

В очередь сканера или вкладку «IN» камеры можно перетащить обычный текст из блокнота или другого окна — каждая непустая строка станет отдельным кодом в списке.

## Если что-то пошло не так

| Ситуация | Что делать |
|----------|------------|
| Курсор показывает, что сброс возможен, но коды не появляются | Обновите эмулятор до актуальной версии; перезапустите программу и повторите перенос. |
| Не удаётся выделить строку в очереди сканера или во вкладке «IN» камеры | Кликните по строке ещё раз — выделение должно работать; при необходимости перезапустите эмулятор. |
| Нужно скопировать код, не убирая из источника | Перетаскивание всегда **переносит** код; для копии добавьте код вручную или через генератор. |
| Коды не уходят дальше по линии | Перетаскивание только заполняет очередь — для отправки запустите устройство кнопкой «R» (см. [Сканер](scanner-widget.md), [Задержка передачи кодов](code-interval.md)). |
