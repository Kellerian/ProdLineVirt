# Как удалить виджет с линии

Лишний принтер, камеру, сканер, перевозчик или генератор можно убрать с рабочего поля по одному — не нужно заново собирать всю линию.

**Где найти:** кнопка «X» в шапке каждого виджета (справа от «R» / «S»; подсказка «Удалить»).

## Перед началом

- Виджет должен быть **остановлен** (кнопка «R», зелёная). Работающий виджет («S») удалить нельзя.
- Если нужно остановить сразу несколько устройств — меню «Управление» → «Остановить» (см. [Массовое управление](bulk-control.md)).

## Удаление остановленного виджета

1. Остановите виджет, если он запущен: нажмите «S» → «R».
   **Результат:** кнопка снова зелёная «R», настройки доступны.
2. Нажмите кнопку «X» справа от «R».
   **Результат:** появляется вопрос «Удалить виджет «…»?».
3. Выберите «Да».
   **Результат:** виджет исчезает с поля и больше не участвует в связях линии. Списки «ИЗ:» и «В:» у остановленных перевозчиков и генераторов обновляются без удалённого устройства. При «Нет» виджет остаётся на месте.

## Если виджет запущен

1. Нажмите «X», не останавливая виджет.
   **Результат:** появляется предупреждение «Остановите виджет перед удалением» — удаление не выполняется.

## Если что-то пошло не так

| Ситуация | Что делать |
|----------|------------|
| «Остановите виджет перед удалением» | Нажмите «S» → «R», затем снова «X». |
| У перевозчика или генератора в «ИЗ:» / «В:» ещё виден удалённый прибор | Остановите этот перевозчик или генератор («S» → «R») — список обновится. |
| Нужно очистить всё поле | Откройте другой файл конфигурации («Файл» → «Открыть...») — перед загрузкой поле очищается целиком, включая генераторы. |
| Нужно остановить сразу много виджетов | Меню «Управление» → «Остановить» (см. [Массовое управление](bulk-control.md)). |
