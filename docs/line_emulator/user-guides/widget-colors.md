# Как отличить типы виджетов на линии

У каждого типа устройства на рабочем поле свой светлый цвет фона — по нему быстро понять роль виджета, даже если подпись закрыта соседними блоками.

**Где найти:** рабочее поле главного окна «Эмулятор производственной линии».

## Цвета по типам

| Цвет фона | Тип виджета | Назначение |
|-----------|-------------|------------|
| Светло-оранжевый | Принтер | Приём кодов от внешнего клиента по сети |
| Светло-зелёный | Камера | Обработка и отправка кодов по сети |
| Светло-фиолетовый | Сканер | Отправка кодов в COM-порт (как ручной сканер) |
| Светло-голубой | Перевозчик | Передача кодов между устройствами на линии |
| Светло-жёлтый | Генератор | Создание тестовых кодов по расписанию |

Кнопки «R»/«S» и поля настроек выглядят одинаково на всех виджетах — ориентируйтесь по цвету подложки.

## Меню и выпадающие списки

Верхняя строка меню («Добавить», «Файл», «Управление») и раскрывающиеся списки на виджетах оформлены в едином стиле с программой:

- **Меню** — светлый фон, тёмно-синий текст; при наведении пункт подсвечивается синим с золотистой надписью.
- **Списки выбора** (COM-порт сканера, продукт, «ИЗ:» / «В:» у перевозчика и генератора) — тёмно-синий фон списка, золотистый текст пунктов.

Если в Windows включена системная тёмная тема, интерфейс эмулятора остаётся светлым и читаемым — отдельно настраивать тему в программе не нужно.

## Если что-то пошло не так

| Ситуация | Что делать |
|----------|------------|
| Два виджета кажутся похожими | Сравните оттенок: принтер — тёплый оранжевый, генератор — более яркий жёлтый; сканер — фиолетовый, камера — зелёный. |
| Цвет не помогает | Прочитайте поле «Название» на виджете или откройте списки «ИЗ:»/«В:» у перевозчика — там видны имена устройств. |
| Меню или список выбора выглядят тёмными и текст не читается | Обновите программу до версии 1.0.0.1.b0002 или новее. После обновления перезапустите эмулятор. |
