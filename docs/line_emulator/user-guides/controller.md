# Карточка «Контроллер» (Modbus / Doypack)

**Текущая версия приложения:** см. начало [README.md](README.md).

## Зачем нужна карточка

На поле можно разместить один или несколько **контроллеров** эмуляции линии Doypack: они слушают **Modbus TCP** на порту карточки (по умолчанию следующий свободный, начиная с **5020**) и внутри запускают цикл обмена Doypack с этим же портом. Внешняя система (например DataManager на другой машине) подключается к **IP вашего компьютера** и **порту карточки** — как к принтеру или камере.

Отдельное поле **IP не вводится**: клиент Doypack внутри карточки всегда ходит на **127.0.0.1** и этот порт.

## Добавление и имя

1. Меню **«Добавить»** → **«Контроллер»**.
2. На поле появится карточка с именем вида **`CTL_5020`** и соответствующим портом. Следующая карточка получит порт **5021** и т.д. (как у принтера со своим генератором портов).

## Поля на карточке

| Поле | Смысл |
|------|--------|
| **Имя** | Подпись на линии и в файле настроек |
| **Порт** | TCP-порт Modbus (целое число). Внешние клиенты подключаются к этому порту на сетевом интерфейсе вашего ПК |
| **Очередь** | Размер очереди для формулы Doypack (1–1000), по умолчанию 10 |
| **Режим** | **Simplex** или **Duplex** — влияет на шаг адресов регистров |
| **Тип** | **Delta** или **Xinje** — набор базовых адресов Doypack |
| **R / S** | Запуск и остановка (как у других устройств): **R** — остановлено, **S** — работает |
| **Добавить переменную** | Добавляет в таблице ниже новую строку для адреса регистра |
| Таблица **«Переменная»** / **«Значение»** | В первой колонке вы задаёте номер регистра (целое число от **0** до **10000**); во второй при работающей карточке показывается текущее значение (только просмотр) |

Пока карточка **запущена** (кнопка **S**), недоступны только имя, порт, очередь и списки **Режим** / **Тип** — как у принтера. Кнопку **«Добавить переменную»** и первую колонку таблицы можно менять и при остановленной, и при запущенной карточке.

## Таблица регистров на карточке

Таблица под полями нужна, чтобы **смотреть**, какие сейчас значения лежат в выбранных регистрах у запущенного контроллера. Запись в регистры из таблицы не выполняется.

**Где найти:** на самой карточке «Контроллер», под строками «Очередь», «Режим» и «Тип».

### Перед началом

- Карточка контроллера уже стоит на поле (через меню **«Добавить»** → **«Контроллер»**).
- Чтобы во второй колонке появились числа, карточка должна быть **запущена** (кнопка **S**).

### Пошаговая инструкция

1. Нажмите **«Добавить переменную»**.
   **Результат:** в таблице появится новая строка с пустым полем в колонке «Переменная» и пустой колонкой «Значение».
2. В колонке **«Переменная»** введите номер регистра одним целым числом (от **0** до **10000**).
   **Результат:** адрес отображается в ячейке; пока карточка остановлена (**R**), колонка «Значение» остаётся пустой.
3. Нажмите **S**, чтобы запустить контроллер.
   **Результат:** в колонке «Значение» начнут появляться числа и регулярно обновляться, пока карточка работает.
4. Сохраните файл линии обычным способом.
   **Результат:** в настройках сохраняются **только адреса** из колонки «Переменная» (в том порядке, сверху вниз); пустые строки в список не попадают. Значения на экране в файл не записываются.

Наведите указатель на таблицу: во всплывающей подсказке кратко указаны допустимый диапазон адресов и типовые стартовые номера очереди для режимов Delta и Xinje.

### Если что-то пошло не так

| Ситуация | Что делать |
|----------|------------|
| При сохранении файла линии появляется сообщение об ошибке из-за адреса | Проверьте строку, которую называет сообщение: в колонке «Переменная» должно быть целое число от 0 до 10000, без лишних символов. Исправьте текст и сохраните снова. |
| Во второй колонке пусто, хотя контроллер должен работать | Убедитесь, что карточка **запущена** (**S**). После остановки (**R**) значения на карточке специально очищаются — это нормально. |
| Осталась лишняя пустая строка в таблице | Отдельной кнопки «удалить строку» нет: пустая строка при сохранении не попадёт в файл, но может остаться на экране до следующей перезагрузки конфигурации. |
| Нужно отдельное окно «поллера» с IP и кнопками опроса | В эмуляторе такого окна нет: опрос идёт только с карточки контроллера после **S**; остановка — кнопка **R**. |

## Удаление

Кнопка **«X»** снимает карточку с поля только если она **остановлена** (кнопка **R**). Если показывается **S**, сначала остановите карточку.

## Сохранение в файл линии

Карточки попадают в JSON в секцию **`controllers`**. Старый файл без этой секции откроется без ошибок — список контроллеров будет пустой.

## Массовое управление

В **«Управление»** есть пункты **«Запустить» → «Контроллеры»** и **«Остановить» → «Контроллеры»**. В **«Всё»** контроллеры стартуют **после** принтеров, камер и сканеров и **до** перевозчиков и генераторов; при остановке **«Всё»** порядок обратный.

В меню **«Очистить данные»** контроллеров **нет** — у карточки нет очередей штрихкодов.

Контроллер **не** появляется в списках связей перевозчика и генератора (только принтер, камера, сканер).
